# CN360live

360° VR Spatial Camera Viewer

## Stack
- Three.js (CDN) — equirectangular sphere renderer
- WebXR — immersive-vr head tracking (Pico 4 compatible)
- Vercel — static hosting

## Features
- Full-screen 360° panorama viewer
- Mouse / touch drag to look around
- Scroll / pinch to zoom FOV
- Upload any 360° equirectangular image
- Live camera stream via HLS/WebRTC URL
- ENTER VR button (WebXR immersive-vr)

## Deploy
Connect this repo to Vercel.
Set **Output Directory** to `public` in Project Settings.
